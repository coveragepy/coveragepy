- Feature: ``[run] source`` entries (and ``--source``) can now be glob
  patterns, for example ``packages/*/src``.  A pattern is expanded to the
  directories it matches when measurement starts, so monorepo packages are
  measured, and their un-executed files reported, without listing each one.
  A pattern that matches nothing issues a warning (``source-glob-no-match``).
  Closes `issue 2400`_.
